# Erfan Ebrahimi · Portfolio

Persian developer portfolio built with React, Vite and Framer Motion, featuring skills and project showcases.

<p dir="rtl">پورتفولیوی شخصی با معرفی مهارت‌ها، نمونه‌کارها و بخش‌های متحرک.</p>

[Source](https://github.com/Erfan-Ebrahimi/erfan-cv)

## Stack

React · Vite · Framer Motion · Sass · React Router

## What's inside

- Animated home, about, skills and project sections
- Persian content and portfolio navigation
- Project links and a downloadable résumé

## Local setup

```bash
git clone https://github.com/Erfan-Ebrahimi/erfan-cv.git
cd erfan-cv
npm ci
npm run dev
```

Create a production build with `npm run build`. Preview it locally with `npm run preview`.

## Project layout

- `src/components/` — portfolio sections
- `src/constants/` — skills and project data
- `src/assets/` — illustrations, images and résumé
- `src/utils/` — motion helpers

## Project notes

Project and contact links are defined in the source. Review them before using this as your own portfolio.
